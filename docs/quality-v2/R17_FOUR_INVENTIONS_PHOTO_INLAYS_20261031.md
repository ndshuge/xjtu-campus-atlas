# R17 | 四大发明广场真实照片参考铺装修复（2026-10-31）

## 依据与许可

- 本地现有原始照片预览：`public/assets/reference/library-front-2021.jpg`。摄影者 Liuxingy，2021-09-06，CC BY-SA 4.0。详细原页、署名与授权见 `public/assets/reference/README.md`。
- 该照片显示钱学森图书馆前的四大发明广场上，浅色石材铺装之间有多组深色矩形/直线嵌条。无法从单张地面透视照片确定精确位置、线宽、材质配比，也没有照片所示年份之外的现场复核。
- 本轮全部为**照片指导的示意性、低高度装饰几何**，没有改动 OSM 道路、建筑轮廓、雕塑基础、草坪边界、碰撞和高程。不能宣称测绘精度。版权图片仅用于看图对照，**没有复制成地面贴图**。

## 施工范围

- `src/plaza-photo-inlays.js`：两组估算的深灰色石材矩形条带，整体控制在现有 `PLAZA_PAVING` [-76,13]×[-42,10] 内；一次生成 8 个互不覆盖的狭长矩形，共 16 个三角形，聚合成一个 BufferGeometry。
- `src/plaza-terrain.js`：作为 1 个 Mesh 叠加到既有广场铺装，Y 为 `BASE+.128`，保持原高度不变；四块独立雕塑落脚圆盘、四处周边草坪不受影响。
- `src/world.js`：仅增加可复现的同机位视觉测试参数 `?inspection=plaza-photo-inlays`。最终相机采用近俯视机位，避免原斜视视角受到附近大型楼体屋顶遮挡。
- `tests/plaza-photo-inlays.test.mjs`：RED (源模块不存在) → GREEN 2/2，检查 OSM 铺装边界、集合渲染顶点、草坪与雕塑基座不叠加、中心保留通路。
- `package.json`：测试并入全量 `npm run verify`。
