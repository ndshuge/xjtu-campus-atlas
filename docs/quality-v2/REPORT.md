# 西安交通大学兴庆校区 3D · 第三轮交付核验（2026-10-25）

## 发布范围和真实性边界

在原 xjtu-campus-atlas Three.js + Vite 工程内升级，不替换 OSM 坐标、139 栋建筑基底、384 条道路，保留搜索、导览、轨道/步行模式、白昼/暮色/夜景、图层开关和可分享地点链接。

**这是高完成度的交互式 3D 校园图志，不是摄影测量/BIM/照片级实景复刻。** 之前尝试给钱学森图书馆入口摆放圆形水池与三角雕塑，实际对照已确认不应在该位置凭空制作：学校校友资料记录的是校园中轴上、图书馆与腾飞塔之间的水池；项目 OSM 数据亦在约 (x=-30,z=-291) 标有水域。删除这两个无空间来源的装饰物。<https://alumni.xjtu.edu.cn/info/1041/4898.htm>。此处理优先保证建筑和景观地理关系可信。

## 本轮实现

- **高空到地面视觉一致性：** 通过 Three.js Sky 模型替换纯色天空的视觉平淡，三种光照状态仍分别控制日景、暮色、夜景；外观是程序化视觉近似，非当天气象。
- **真实数据上的景观增强：** 所有道路与铺装使用本地确定性程序纹理；OSM 实际水面增加细微蓝绿纹理和石质岸线描边，不创建新的池塘；草木增加不规则冠形和部分针叶树近景层次。
- **地面漫游入口选点：** `src/walk-placement.js` 综合建筑平面、现有水域、树木净空、直视路径上其他建筑遮挡和四面候选方向计算安全相机位置。建筑索引与运动仍采用已有碰撞逻辑，不重新定义地理坐标。
- **地面漫游移动：** 已有 `isWalkable` 会避开 OSM 楼房/水域/树干，鼠标拖动环顾、WASD/方向键/Shift 仍可使用。
- **参考资料链接：** 图书馆详情增加学校正式图文链接 <https://www.xjtu.edu.cn/info/1112/2225136.htm>；移除会返回 404 的招生网旧地址。
- **可重现的数据验收：** 新增 `scripts/verify-walk.mjs`，覆盖真实校园地标、安全空间选择、遮挡样例和道路几何 UV 连续性。生产构建中不引入外部字体、图片或云端密钥。

### 仍未达标或待真实素材的项目

1. 建筑幕墙与窗格仍为程序化材质，真实度受到照片和 BIM/扫描许可的约束；没有真实 3D Gaussian Splatting 数据，**未训练高斯**。
2. 3D 环境装置和植被仍有示意性。精细地标应使用实际许可照片多视角标定后替换 GLB，而不是凭空虚构。
3. 一些 390px 标签及小文字仍过细，需要持续做触摸/可访问性优化；Taste Inspector 先前仍报出部分字体与符号告警，不能宣称人类审美已认可。
4. 本轮没有验证真实 iPhone Safari 或公布新的真实设备 FPS，浏览器截图只能证明 WebGL 在隔离 Edge 运行。

## 前端细节验收

本轮运行真实 Taste-Skill app inspector，并进行至少一次“观察 → 修复 → 重看”的移动端 UI 循环。修复了全屏按钮误判为 emoji、标题层级、部分过小的操作标签、按钮装饰阴影和手机详情卡滚动条。390×844 的最终截图以 `final-mobile-library.png` 为准，显示完整地点详情和底部动作按钮，无永久滚动条覆盖。

最终 inspector 仍为 **1 FAIL / 3 WARN**：通用检查器没有识别此 WebGL 地图工作台的标题位置（页面可见品牌标题和地图说明，作为产品例外待继续审视）；89% 可见文字小于 13px、暖色背景以及开发服务器检测属于告警。自动检查结果保存于 `taste-final-v3/report.json`，不是人类审美认证。没有借用未授权的 Designeer 图像素材。
