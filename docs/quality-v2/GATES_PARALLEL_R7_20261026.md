## 修改范围

- `src/campus-perimeter.js`：保留 OSM 原边界和门洞；缩小、淡化高度统一的仿墙与密集竖杆，不虚构通用砖石立面；基于门区、道路穿界点和多点建筑轮廓检测跳过冲突墙段；可传入经测量或人工核实的树干位置作为额外几何避让，**当前共享 world 尚未传入树干测绘数据**。
- `src/north-gate.js`：调整支撑柱趋向照片可见的上宽下窄体量，修正朝路面向时校名照片纹理的左右镜像问题；保留抽象浮雕说明。
- `src/south-gate.js`：使 2011 年模型中的实体校名墙避开 OSM 南门两个通行节点，移除没有定位依据的后方楼体和横跨车道的护栏；南门真实校名墙的确切水平位置仍待测绘。
- `src/secondary-gates.js`：无照片的东南门、西南门、东北门、西北门仅用低干扰开放式定位标记；移除原先臆造的石柱顶棚造型。
- `scripts/verify-gates.mjs`、`scripts/verify-perimeter-avenue.mjs`、`scripts/verify-vegetation-clearance.mjs`：新增/调整入口限界、未验证外观禁用、墙段碰撞与示意材料回归检查。

- Edge Headless **真实 WebGL 画面**：1440×900 桌面与 390×844 手机宽度；不是 iOS Safari 物理设备。
- **最终有效验收证据**统一收录于 `docs/quality-v2/gates-parallel-r7-accepted/`：北门、北缘视角、南门、东南门，各 1440×900 与 390×844 两套，共 8 张截图；`browser-results-accepted.json` 是从逐项确认了正确选择地点、零脚本异常、零 HTTP 错误的独立测试中提取，舍弃了初始连续 hash 导致重复南门的错误镜头。
- 辅助取证留存于其他 QA 原始工作目录；其中连续 URL hash 切换导致的错误镜头**不作为有效成果提交**。东南门通过单独启动的浏览器会话重新渲染，选中项确认为“东南门”而不是“南门”。
- 最终北门图证实中文位于画面左侧、英文位于右侧并改为两行；新增校门测试防止该顺序回退。390px 近景依然会裁切两翼，已给出仅供集成方使用的镜头补丁，**未声称移动端外观验收全面通过**。
