# 2026-10-25 北门视觉整改与自行验收 R3

## 问题与修复

用户反映前一版本校门仍不真实。本轮采用多次真实 WebGL 浏览器截图检查，而不只运行单元测试。

- 门的查看镜头从原本校内后方改为校外正立面；南北门采用不同的外侧方位，移动端采用独立宽角镜头，俯视和全景模式重新恢复标准视场。
- 重新生成北门连续弧形屋面：正面檐板、顶部与底部有独立曲面及 UV；内侧承重柱、低矮侧墙、深色浮雕。
- 中文/英文题字从路外观看的左右顺序经过实际截图纠正。校门选中时关闭远处大量遮挡视线的建筑标签，其他场景限制标签数量。
- Wikimedia Commons 历史照片 XJTU_Main_Gate.JPG 的真实书法题字，裁出 388x130 像素的参考纹理，并适度提亮后映射到门檐。2011 年原图摄影师 IronBlood，遵守 CC BY-SA 3.0 并已记录派生变更。自制瓷砖微纹理增强材质层次。
- 程序、模型、数据、授权记录全部参与构建与自动测试。正式发布须另核对 Pages 的 HTML / JS / 照片 / 纹理资源及完整 390px 画面。
