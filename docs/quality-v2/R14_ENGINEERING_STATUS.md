# R14 技术债与施工状态（2026-10-28）

基线：源码 `99eb615cc0355a259f71cba274128032d2eac475`，正式 Pages `55cf056ef0d1fbc0633b960dc069561b82aa10a3`。R14 使用独立工作树，正式首页及 R13 未提交成果保留。

## 按影响排序

1. **性能归因与动态帧时间（P0）**：已有 Intel Edge 测试的 P95 波动大，静态 FPS 不能证明回退或改善。植被实例更新和动态阴影是待测假设；对相同场景、GPU 和画质做交替重复及单项消融，隐藏树木只用于诊断，不能作为交付优化。显存、GPU 利用率和真实功耗缺少可靠浏览器数据时标为不可用。
2. **真实移动设备稳定性（P0/P3）**：已有浏览器模拟、上下文丢失恢复代码和 R11 CDP 测试；真实 iPhone Safari 后台回收、长时发热和功耗尚无验收设备。复用测试，分别记录实际观察与模拟限制。
3. **建筑可验证真实性（P1）**：图书馆北馆四层、书库五层、南馆特定部分 49.75m 有文献；下沉庭院的位置和高差、弧形架空通道的定位均未证实。思源活动中心和西迁博物馆已有单一专属资产，不应重叠重建。先补可靠照片和无遮挡对照，不将估算称作测绘。
4. **地图与 3D 场景融合（P2）**：既有高德自定义层实测为 WebGL 1，Three.js r186 需要 WebGL 2；双 Canvas 不共享深度。隔离实验比较共享 WebGL 2 深度与双 Canvas 遮挡，使用开放校园数据及标明示意的几何，不引入商业瓦片或密钥；在完整验证前不迁移正式引擎。
5. **资源和回归控制（P2）**：目前全景 139 栋建筑、384 段道路、115 片场地、2092 株示意植被；测试渲染三角面和调用次数随机位变化，非模型独立数量。保护南门修复、搜索、圆球、移动手势及既有资产；生产构建和完整测试需在隔离树运行。

## 2026-10-29 集成与回归

- R14 对分类未变化的植被跳过矩阵、颜色和包围球重建；跨 LOD 阈值及 WebGL 强制恢复仍更新。2,092 棵合成树 CPU 微基准分别为缓存命中 P95 0.038 ms、强制重建 P95 0.524 ms，仅代表该局部工作，不能推断 GPU 或整帧加速。真实 Edge 帧间隔波动大，尚未证明 20% P95 改善。完整方法与 A/B 原始资料见 [性能记录](R14_PERFORMANCE_20261029.md)。按空间分批的候选因为全景绘制调用增加而仅保留为实验，没有纳入生产。
- [MapLibre + Three 遮挡实验](../../experiment/r14-map-depth/README.md) 对 OSM 校园轮廓上的合成墙、球，在桌面与 390px 模拟视口的前后位置完成共享深度与双 Canvas 对照；前者通过像素断言，后者在墙前视角错误显示墙后的球。此结果不证明高德 WebGL1 或完整校园场景可直接迁移；地图实验上下文恢复、许可底图和真机仍需验收。
- [西迁博物馆证据记录](R14_MUSEUM_EVIDENCE_20261029.md) 增加审查机位与已知照片来源，但部分视角仍被树遮挡，特写裁切；未完成真实照片逐项核对，也没有修改生产建筑形体。图书馆地下高差与弧桥依然缺少定位证据。
- R14 集成后 `npm run verify` 通过；`npm run build -- --outDir build-r14-integrated` 通过，主 JS 792.94 kB、gzip 223.20 kB。南门、图书馆、主楼、圆球及校园数据源相对 R13.1 无差异。
- 本机 Edge 的 390×844、DPR 2 手机模拟中，圆球拖动、缩放、朝北、键盘、复位、漫游和地图平移检查通过；图书馆机位单独启动浏览器后平移、双指缩放和 `WEBGL_lose_context` 模拟恢复通过，没有记录页面或 HTTP 错误。连续运行多个机位的旧测试中第二个机位手势失败，独立会话复测成功，原因可能是跨页面测试状态残留但尚未证实；原始失败及单独复测均保留，不能报为整套连续手势稳定性通过。以上均不是 iPhone Safari 或设备后台回收验收。
