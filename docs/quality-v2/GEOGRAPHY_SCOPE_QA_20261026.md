## 可重复的地理验收
`node scripts/audit-campus-boundary-20261026.mjs` 在本机重新计算两个闭合边界环：整体东西跨度 **1137.534 m**，南北 **1125.319 m**。在学校 2015 年档案的不同范围口径下，数值差异为东西 **-401.106 m**，南北 **+40.887 m**；**不是已证实的 GIS 缩放错误**。
新自动检查覆盖 WGS84 坐标方向与米制单位、边界环闭合、有限点、合理跨度区间以及 24 个 OSM 经纬度锚点在本地投影后的坐标误差；本次最大误差 **0.0006 m**（源数据舍入精度层面，不是地面测绘精度）。不应解读为 0.6 毫米真实建模精度。
测试集成到 `npm run verify`。既有核心建筑、立面及图片测试应维持通过。
