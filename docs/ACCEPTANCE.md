# 交付验收记录

日期：2026-10-25。此记录分开说明地理数据、实际浏览器和部署，避免把单一检查当成全部完成。

## 数据与网格

独立子代理从 5,836 条原始 OSM 记录重算边界和覆盖，得到 139 个校内建筑、114 个有名建筑、12 个层数标签、0 个 OSM 高度标签；没有发现当前口径下的遗漏或多余建筑。原始初审在 `INDEPENDENT-AUDIT.md`，保留其当时状态；以下收尾修正覆盖初审的待办。

`npm run verify` 的 12 项检查通过，结果在 `verification.json`：独立原始建筑 ID 集、坐标投影、闭环、有限网格值、屋顶面积与真实基底相符、北门至思源活动中心的中轴次序、东田径场在图书馆东侧、高度来源与建设提示、道路/地表有效、漫游落点存在、源码语法、许可与生产入口引用。基础建筑挤出 3,860 个三角形，另有重点地标、树木和设施。

初审后修复：

- 源码缓存输入改为项目内 `data/source-osm.json`，可独立重建。
- 投影采用 WGS84 椭球在中心纬度的经纬尺度，替换粗略的 111,320 m/° 常数；原始经纬度保留在源快照。
- 图书馆最高体量用学校 2016 年报道的49.75m控制；高度配色、详情、说明和下载数据区分“官方文献”与“OSM 层数估高/其他估计”。主楼23层仍只用于推算。
- 修复环绕按钮状态不同步、加载计时随页面存活增长、低帧率统计截断。
- 地面漫游改为从建筑南侧附近道路开始，避免默认贴墙；使用62°视角，建筑/水面碰撞与水平移动速度按时间积分。
- Three.js 弃用的 Clock/PCFSoftShadowMap 改为 Timer/PCFShadowMap。

## 实际浏览器证据

已在 Codex 内置浏览器实际启动 WebGL 2 画面，观察校园全景、图书馆近景、日夜切换、搜索与选择、带出处的49.75m详情、地面漫游与键盘行走。W 键持有1秒后坐标发生约5m变化，地面视点维持2m。已修正当时发现的贴墙落点。

初次桌面检查为1440×900，场景实际含139建筑、2,081株实例化树木，约526k三角形、88次绘制，当前浏览器近期帧约113FPS、场景初始化约216ms。它们是当次浏览器读数，不是冷缓存全站加载时间，也不是其他设备性能承诺。移动窄屏初始约319px，观察到画面与折叠探索面板正常；没有据此宣称完成所有手机实机触控验收。

后续生产版本已在另一 Chromium 浏览器重新渲染全景并保存整页实际截图。截图为运行结果，非设计稿。完整视图和图书馆近景图位于交付目录。后续浏览器控制连接发生超时，因此未把所有移动宽度、双指缩放、自动导览的完整点击回归冒充已测；已提供响应式布局与实际浏览器可体验版本。

早期控制台曾出现 Three.js 弃用提示，已按实际依赖源码修复。早期已运行路径没有捕获到阻塞性的JS/GLSL错误；最终版本的语法、构建及全景实际渲染通过。部署后的网络资源状态单独核查，不把HTTP成功当成完整GPU验收。

## 静态发布与授权

生产代码约653kB（gzip约171kB），校园派生数据约201kB；加载不请求外部地图API、CDN、在线模型或照片。OSM源记录子集约352kB，用户主动下载时才请求。

源码带MIT许可、Three.js完整MIT通知、OSM的常驻署名、ODbL条款链接、派生数据与相关源记录下载。学校官方平面图、照片和校徽只用于研究，没有打包再发布。三个参考项目的模型/贴图/校园数据没有进入作品。

`dist/` 为完整静态站点，源码、原始快照、数据生成脚本、构建脚本、启动器都在交付项目内。公开部署的成功状态、生产URL、源提交和回执由发布工具返回后另存到交付目录的访问说明和部署回执；站点预期URL或创建项目本身不算已上线。

## 保留限制

仅兴庆校区。已包含的轮廓完整度受限于OSM社区；新建、改名和在建区域可能落后于现场。多数高度和全部外立面为推测，地面为平面近似；没有室内、真实三维测绘、街景或导航通行授权。当前漫游不模拟门禁、台阶和桥面高度。
