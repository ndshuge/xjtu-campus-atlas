# 西交校园 3D 独立只读审计

日期：2026-10-25。审计对象：`outputs/xjtu-campus-3d`。只读审计作品代码与数据，执行独立 Node 校验；未修改作品、未操作浏览器。主代理同时迭代，以下区分已重查修复与仍待同步的中间状态。

## 结论

地理数据、建筑覆盖与基础网格初审通过。原始 OSM 独立重算得到 **139 个校内建筑、114 个有名称、12 个 OSM 层数标签、0 个 OSM 高度标签**，与原始公开声明相符。当前没有发现会导致主体校园布局错位、轮廓丢失或漫游卡死的阻塞问题。

正式发布前仍需同步新查到的官方高度证据与 UI 文案、固定加载时间诊断值。浏览器画质、帧率、控制台、触控与公开部署由主代理另行实际验收，本报告不替代这些证据。

## 官方地图与高度证据

- 已实际读取学校 [交大地图页面](https://vi.xjtu.edu.cn/qt/jddt.htm)，并目视核查本机 `work/research/official-campus-map.png`。图中确认北门—中一楼—腾飞塔—钱学森图书馆—四大发明广场—主楼—思源活动中心的中轴次序；当前数据相对位置相符。图中有“教三楼（在建）”，当前 OSM 的教二楼/教二100 与新版图的时效差异已逐建筑提示。
- 四大发明广场是官方图中的真实名称，但应用中的经纬度中心由解释性定位给出；独立放在 `interpretive` 数组并提示来源的做法正确。
- 已实际读取学校 [钱学森图书馆介绍](https://www.xjtu.edu.cn/tsda/qxstsg.htm)，确认南北楼组成及建设年代。
- 通过官方搜索索引与直接 HTTP 成功读取 [2016-11-21 学校报道](https://news.xjtu.edu.cn/info/1002/66472.htm)：南楼地面高度 **49.75 m**，主体地面 11 层；连屋顶机房水箱计数的口径另有说明。该高度可作为官方历史文献证据，但不是本项目现场测量，也不是南北楼整个轮廓统一高度。
- 通过直接 HTTP 读取 [学校主楼报道](https://news.xjtu.edu.cn/info/1219/143933.htm)，确认主楼 23 层宣怀厅。**23 × 3.5 m = 80.5 m 是推算**，报道不提供主楼实测总高；另加屋顶也必须继续标为示意。
- 复查时 `campus.json` 已将图书馆改成 `official-document-height` / 49.75 m；主楼改成 80.5 m 并附 `heightEvidence`，仍为估高。`world.js` 图书馆最高体量已改为49.75 m。

## 需在发布前收尾的问题

### P2：新官方高度来源尚需同步到所有显示与说明

复查时数据已出现 1 栋 `official-document-height`，但 `src/app.js` 仍用旧的“全部高度均非实测”图层文案，证据颜色与详情仍只按 `levels` 二分。这会把官方文献高度与纯推测混为同一类。应分别展示 OSM 高度、OSM 层数估高、官方文献高度、其他推测；OSM 的高度标签仍是 0 栋，不能把官方报道写成 OSM 标签。公共数据 README 与主 metadata notes 也应说明这一例外。

### P2：加载诊断值仍在随页面存活增长

复查时 `src/app.js` 的 `campusDiagnostics()` 仍返回 `Math.round(performance.now()-start)` 作为 `totalLoadMs`。每次读都会增大，因此不能拿它证明加载速度。应在完成初始化时一次性保存数值。主代理已表示正在修复；本报告尚未把承诺当作完成。

### P3：FPS 统计对低帧率有截断

`world.js` 把帧 dt 限在 0.1 s 后同时用于 FPS 计算，极慢设备的显示值最低约 10 FPS。移动积分可保留 dt 上限，但统计应使用未截断的实际间隔，避免低性能验收显示过于乐观。

## 已发现并复查修复

- **环绕按钮状态**：初审 `setAuto(false)` 未更新按钮，切换地点/俯视/漫游会出现视觉状态不同步。最新 `setAuto` 已同步 active 和 `aria-pressed`。
- **数据构建输入路径**：初审 `prepare-data.mjs` 依赖作品目录外的 `../../work/research/xingqing-osm.json`。最新默认输入改为作品内 `data/source-osm.json`，该文件已存在（4,314,107 字节）；独立携带源码后可获得数据重建输入。
- **Three.js 许可**：当前 `public/THREE-LICENSE.txt` 已存在，与实际依赖中的完整 MIT LICENSE 字节一致。
- **图书馆原58m示意峰值**：已被官方文献校正为49.75m；造型仍为解释性模型，UI不得据此宣称整体达到竣工图精度。

## 可接受的精度与性能限制

- 当前投影每纬度使用 111,320 m。按 WGS84 椭球在校园纬度独立算得，经向约110,926.86 m/°、纬向约92,116.20 m/°；当前 X 尺度约低0.1056%，Z尺度约高0.3544%。主校区1.05km南北跨度约多3.7m，原点附近地标最大位置误差约2m。当前明确“局部平面近似”可接受，但不要引用 CUHK README 的 `<0.01%` 或声称测绘精度。
- 路线来自 OSM 中心线；路宽多为类型默认值，桥梁暂铺在平地。树木、灯柱、看台、球场划线、窗格与屋顶不是测绘资产，现已有示意说明。
- 建筑单批合并且保留顶点建筑 ID，树木与灯采用实例化，基础建筑三角形数量很低；源码层面没有发现必然导致性能失控的渲染结构。`preserveDrawingBuffer:true` 会增加部分设备开销，可在不需要保留帧缓冲时关闭；实际影响须以 GPU 浏览器测量为准。
- 地理数据有常驻 OSM attribution、ODbL链接、派生数据与源快照下载、公开数据许可说明。官方学校地图/照片只放在研究目录，没有打包到站点 public；参考项目资产没有进入模型。
