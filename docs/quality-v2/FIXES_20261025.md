# 2026-10-25 · 操场闪烁、地标缺失、标签抖动整改

## 从用户 iPhone 截图复现的问题

- 东田径场跑道与球场线条在移动镜头时闪烁。
- 四大发明广场仅有文字示意，缺少可辨识的实景地标；此前推定点落入一栋 OSM 未命名建筑。
- 标签随视角移动抖动及遮挡边界反复出现/消失。

## 已实际改动

1. **操场多层共面修复：** `src/world.js` 对 pitch 不再同时画通用地面与运动场地面；每个球场只保留一个基础面。跑道及场地标线提高至独立高度（BASE + 0.22），关闭线条深度写入，跑道圆弧改为两段半圆加两条直线，避免原先的数学符号分段跳变造成交叉线。
2. **四大发明广场资料校验：** 官方文明网有“四大发明广场”图片，学校旅游资料明确位于主楼北、钱学森图书馆南。原推定点 [-31.32,19.967] 位于 OSM 未命名建筑内；改为校园中轴约 [-31.32,0]，通过占用测试。仍为**推定中心**而不是测绘坐标。
3. **公共艺术示意：** `src/four-inventions.js` 增加金属书页式雕塑的参数化轮廓，参照学校照片中的金属公共艺术，不直接下载官方图片，不宣称尺寸、角度、朝向与真实场地完全一致；详情可打开学校官方地标图库。
4. **标签定位稳定性：** `updateLabels()` 每渲染帧同步定位；投影坐标整数化、屏幕移动插值，并将标签间临界遮挡判断改为连续 10 帧滞后，降低边界反复闪断。
5. **自动化回归：** `scripts/verify-render-regressions.mjs` 断言广场在校区内且不覆盖建筑、有可用几何、操场单独绘制与标签逐帧更新等。
