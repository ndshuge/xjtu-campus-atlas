# 交大西迁博物馆：入口视觉修正

## 依据

- [上海交通大学新闻网转载的上观新闻报道](https://news.sjtu.edu.cn/mtjj/20200709/127509.html)，页面标注 2020-07-04，照片实际拍摄日期及使用许可未注明。本次仅本地人工查看照片；没有将图片或其纹理纳入网站或 Git。
- [西安交通大学馆舍介绍](https://www.xjtu.edu.cn/tsda/jdxqbwg.htm)：确认其在兴庆校区、四层、建筑面积约 3760 平方米。页面更新日期不等于照片拍摄日期。
- 该报道照片显示高主体由浅色大面板和深色竖缝组成，门头下有窄入口、深色竖向构件及一块暖色展板。模型将这些特征用于近似视觉表现；具体开口、深度、门头尺寸与背面形态均未测量。不能由这张照片推断改造后现状，亦不声称全楼比例准确。

## 改动与验证

保留 OSM `way/1167525875`，继续由 `relocation-museum-asset.js` 单独负责外观；保留拾取与图层接口。将入口低翼原有大面积玻璃改成浅色门头、局部窄玻璃门、深色竖条与一块暖色面板，避免它像普通玻璃盒。高低体量划分、入口朝向及 14 米高度仍为估算，不改变地形。

新版固定机位：[桌面入口](r15-museum-final/r14-museum-entry-1440.png)、[手机入口](r15-museum-final/r14-museum-entry-390.png)、[桌面斜视](r15-museum-final/r14-museum-oblique-1440.png)、[手机斜视](r15-museum-final/r14-museum-oblique-390.png)。Edge 截图是浏览器实渲染，390px 为模拟视口并非真实 iPhone；入口机位距离过近，存在裁切；斜视用于检查总体空间。

专项验证保留屋顶覆盖、建筑源数据、采样和拾取；与实拍相比，主体高低体量、立面深度、台阶和侧后方仍简化，应继续保留为示意。
