# R14 西迁博物馆：证据与固定机位

本轮复用 R13 的单一资产 `src/relocation-museum-asset.js`，未修改生产建筑、地形、树木或正式网站。这里记录的是照片审查能力，不代表完成真实建筑重建。

## 可追溯实景来源

* [西安交通大学介绍](https://www.xjtu.edu.cn/tsda/jdxqbwg.htm)：页面更新于 2026-07-10，确认位于兴庆校区、2018-12-11 开馆、建筑面积约 3760 平方米及四层，并有馆舍照片。更新日期不是拍摄日期；拍摄日期未知。学校版权所有，许可未明确，仅供人工对照，未复制或分发图片。
* [学校新闻网馆貌专题](https://news.xjtu.edu.cn/info/1193/181392.htm)：2022-04-22 发布，图注标注博物馆外观，署名交大西迁博物馆；实际拍摄日期未注明。许可未明确，仅供人工对照。当前环境直接打开该站图片失败，故本轮不能声称完成逐项照片视觉对照。
* [门头改造采购公告](https://info.xjtu.edu.cn/info/1045/46063.htm)：说明存在门头、局部外立面及周边景观改造采购事项；公告不证明实施完成日期或现状。

OSM `way/1167525875` 提供现有底图多边形；4 层对应的 14 m 是程序估算而非测绘。学校建筑面积和 OSM 多边形面积的统计范围不同，不应互相替换。

## 截图与审查

`buildings-r12-review.html` 的 `r14-museum-face`、`r14-museum-entry` 和 `r14-museum-oblique` 为仅用于审查的固定机位；未改生产相机与建筑。正面从现场植被外观察会被树冠覆盖；因此将视点放在树阵与立面之间，以避免通过隐藏树木制造误导。

* [无遮挡主体局部，桌面](r14-museum-close/r14-museum-face-1440.png)、[手机](r14-museum-close/r14-museum-face-390.png)：只能检查部分板块与窗带，不能判断整体比例。
* [无遮挡入口局部，桌面](r14-museum-close/r14-museum-entry-1440.png)、[手机](r14-museum-close/r14-museum-entry-390.png)：能检查入口表面，但近景裁切，不能判断入口实际朝向。
* [整体斜视，桌面](r14-museum-review-new/r14-museum-oblique-1440.png)、[手机](r14-museum-review-new/r14-museum-oblique-390.png)：显示建筑与相邻空间；存在树木遮挡与透视变形。
* [R13 原正面桌面](r14-museum-review/r13-museum-front-1440.png)与[手机](r14-museum-review/r13-museum-front-390.png)：供同资产不同机位比较，不是新旧建筑模型对比。

从实际渲染可见，模型的高低块、板面分割、入口均呈高度简化形态；无法据此判定与真实照片匹配。主体/低翼划分、入口朝西、立面开口、屋面形状、精确高度及现状均未获足够证据，维持示意。图书馆下沉庭院高差及架空通道同样缺少剖面、定位或高程证据，不能据此施工。

截图由本机 Edge 无界面 WebGL 生成，`browser-results.json` 含视口、相机和错误记录；移动截图为模拟视口，并非真实 iPhone Safari。帧率非本次性能基准。
