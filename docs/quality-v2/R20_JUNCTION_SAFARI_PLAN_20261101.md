# R20 校园赛车路口稳定性与真实 iPhone Safari 验收准备

## 目标
承接 R19 的 110 条 OSM 连通道路、R8 RaycastVehicle 和原有校园场景，增强路口物理接缝与可视路面高度的一致性。制作一个仅明确启用时显示的 iOS Safari 实机诊断面板（收集帧率与驾驶/触摸证据、可导出 JSON），不能把 Windows Edge 模拟记录当作真机证明。

## 技术选型
A. 改为全网三角网格 / Heightfield：真实高程不可得、易超工程，不采用。
B. 继续沿用 R19 分段 Box，但不处理路口：用户已报告需要提升路口驾驶，不能覆盖问题。
C. **采用** 当前可视路面标高对应的 Box + 仅在共享原始节点、路口出现转向的地方增加局部接缝支撑，按车辆邻域加载。物理与视觉仍标记“非实测平面近似”。接缝体必须可清理，不凭平面交叉连接道路。
Safari：官方 Web Inspector 需要 iPhone 开启检查并连接 Mac；当前 Windows 没有可用 USB 会话。直接在网页查询参数 `?safariQa=1` 激活可下载自检报告，用户在 iPhone 打开后完成实际驾驶动作才能产出机型/浏览器/触控/帧率记录。报告未经设备端采集不得宣称设备已验收。
