# R29 建筑无遮挡近景施工方案

R27 视觉验收：工程坊 A（263633887）近景被其他建筑挡住下半部；东一楼（263625677）被树冠遮挡。禁止移动原建筑、树木或修改 OSM。

方案：独立纯函数 `resolveOccludedBuildingView` 使用 OSM 建筑占地、建筑估算高度及已生成的 `world.treePositions`，从照片证据优先机位周围有限角度、距离及高度取候选，评分视线穿过建筑和树冠的风险。仅在点击近看按钮时计算，维持原 Three.js 相机、OrbitControls 和飞行动画。基线没有遮挡时保持原机位。超过照片正立面合理角度不选。数据未实测，因此不能称保证无障碍的实景拍照。

TDD：先写因缺少新方法而失败的测试，再实现最小算法，最后独立三端 Edge 近景截图、QA、全部 R17–R29 相关测试、主校验、Vite 构建。仅修改独立 worktree 的 `src/building-view-occlusion.js` 与 `src/world.js` 和测试，不碰 R28 或南北施工目录；只在验收后发布新 Pages 子目录，原预览保留。
