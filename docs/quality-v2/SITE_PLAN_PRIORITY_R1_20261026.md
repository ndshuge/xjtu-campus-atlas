# 兴庆校区：从照片雕刻转向规划图驱动｜第一轮资料与地形专项

日期：2026-10-26。独立分支 `feature/site-plan-evidence-r1`。不覆盖 Codex 尚未提交的 `feature/canopy-clearance-r6`。

## 已确认来源

- 西安交通大学新闻网 2016-11-21：https://news.xjtu.edu.cn/info/1219/153497.htm。南、北馆建造时间、南楼分段、南楼 II 段 11 层地上/1 层地下、总高 49.75 米，以及南北馆连廊。**这不是公开建筑剖面/施工图**。
- 学校钱学森图书馆官方介绍：https://www.xjtu.edu.cn/tsda/qxstsg.htm；南北楼不同历史期。该页面未提供可用于建模的 CAD 或剖面。
- 官方 2024 年公共通道改造报道：https://news.xjtu.edu.cn/info/1002/213283.htm；证实二层通道修缮，不提供竣工高程数据。
- 校园规划部门：https://ghjj.xjtu.edu.cn/info/1005/2088.htm（2024-05-20）。说明职责，**不代表公开可下载规划图**。
- 用户本次上传的两张实拍：宽台阶及弧形架空步道；摄影日期未提供，两张照片与图书馆本体的准确空间对应关系尚未验证。可观察多层踏步、数处平台、扶手、圆柱支撑和下方人行/停放空间，但**不能据此给出高程、绝对坐标或圆弧半径**。用户原照片保持在对话内，未复制进 GitHub 或充当授权公开贴图。

## 建模优先级变更
P0：整体校园坐标、主要建筑体量、道路及建筑连通关系、真实高差、楼梯和架空通道。
P1：幕墙外观及地面使用感；P2：代表性树阵；P3：小型雕塑局部纹理或铭文。
新增 `campus-site-evidence.json`：逐对象记录来源、日期、版权、可观察事实、缺口以及能否施工的状态；新增 `verify-site-evidence.mjs`：保证没有把没有尺寸/定位的架空通道和真正下沉院落误标为“已完成”。纳入 `npm run verify`。
**不推断**照片里的架空结构一定是连接南北馆的二楼通道。现有 `src/library-forecourt.js` 是明确的平地视觉模拟，真实挖方尚不能实施，因为缺少立面和地下通路数据；不凭空下挖会改变道路/地面穿插。

## 下一步可执行的测量 / 数据申请
1. 查钱学森图书馆 1991 南楼及 2013—2016 整体改造的非涉密竣工总平面、建筑首层及二层平面、剖面、场地竖向标高。
2. 拍或收集能同时看到台阶上下端、平台和建筑固定点的多角度影像；明确用户两张图片的位置。
3. 有了独立校验的建筑底图/测量高程后才建真实 terrain cutout / raised slab，并附道路与人行流线的碰撞测试。
4. 摄影级外观并非该轮验收项；不将本轮“图纸资料库”误称作完成实景建模。
