osm-source.json: the unmodified OSM records selected for this campus rendering, including geometries and tags; not a full OSM planet extract.
campus.json: projected polygons, roads and POIs; names/tags and original OSM IDs are retained. Projection is a local metric plane using WGS84 ellipsoid prime-vertical/meridional radii at the origin latitude, origin 108.9793 E, 34.2473 N, X east, Z south. WGS84 is the source datum. Ground is represented as flat.

139 building footprints within the OSM university relation polygons, 114 named buildings, 12 with building:levels, 0 with explicit height. Completeness means all qualifying mapped footprints in this query, NOT every real building on campus.
Height conversion uses 3.5 m per floor where OSM levels exist. Missing levels use type-based estimates, with interpretive landmark overrides. One exception is the library south building: its maximum modeled mass is 49.75 m according to a university report dated 2016-11-21 (https://news.xjtu.edu.cn/info/1002/66472.htm). It is a historical documented height, not an OSM height tag or a new survey. The library segmented massing remains interpretive. Main Building height uses a university report mentioning a 23rd-floor hall (https://news.xjtu.edu.cn/info/1219/143933.htm): 23 x 3.5 m plus a 4 m interpretive roof, not an actual measured total. Roofs, windows, tree placement, lamp posts, signs, monument shape and pitch striping are procedural, not surveyed.
Four Inventions Square is an interpretive point informed by the university's official campus map. It is separately marked in the interpretive array.
Known currency conflicts: the university's newer plan labels a Teaching Building No.3 construction area; OSM still carries older Teaching Building No.2 geometry/names. The old northern "Westward Relocation Memorial" OSM label is not the southern Museum. The app shows notices on affected records. Buildings under construction/renamed/unmapped may be missing.
