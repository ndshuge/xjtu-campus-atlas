# 钱学森图书馆：官方照片核验与 C 类草坪屋顶增补（2026-10-26）

## 施工前来源核验
- 西安交通大学新闻网《【121校庆】1.4万平米校园屋顶披绿衣》，2017-04-07：
  https://news.xjtu.edu.cn/info/1219/153746.htm
  该校官方稿件明确：2016 年开始屋顶绿化，钱学森图书馆已完成；图书馆属于 **C 类草坪式屋顶绿化**，以地被植物和藤本植物为主，而不是梧桐苑、七彩阁的 B 类花池、灌木、园路和座椅。稿件配有当时校内屋顶照片。**2017 年事实不等于 2026 年现状**。
- 西交官方钱学森图书馆资料，页面 2026-04-13 更新：
  https://www.xjtu.edu.cn/tsda/qxstsg.htm
  用于确认建筑归属兴庆校区及南北楼分期；页面没有提供屋顶植被 2026 年现状实测。
- 学校 2016 年钱学森图书馆正面照片：
  https://news.xjtu.edu.cn/info/1079/52073.htm
  仅用于确认入口及钟楼关系；正面低机位照片无法独立判断屋顶全部植被分布。

## 实际修改
新增 `src/library-green-roofs.js` 并在 `src/world.js` 接入：从原有 `LIBRARY_TIERS` 几何参数推算四级退台中露出的屋顶部分，增加 **12 块**草坪式薄层，不添加官方未证实的灌木、花坛、座椅或游园步道。使用程序生成的确定性草坪噪声纹理，**没有复制、下载或发布学校版权照片**。所有屋顶仍在 OSM 图书馆对应模型的范围内，不更改 `public/data/campus.json`。

新增 `scripts/verify-library-green-roofs.mjs` 并接入 `npm run verify`：验证 12 块非悬浮、有限尺寸的草坪构件，顶高低于钟楼，来源和 2017 日期、2026 年未核实标识均存在，且 `world.js` 实际加载构件。

## 浏览器桌面/手机截图与视觉核对
- `library-green-roofs-desktop-20261026.png`（1440×900）和 `library-green-roofs-mobile-20261026.png`（390×844）：均在 Edge Headless 的本机 Vite/Three.js 实际 WebGL 场景渲染。
- 桌面正面视角：能在建筑右侧退台上看见低矮绿色屋顶层；原有蓝色幕墙、钟楼、馆名与圆形庭院保持可见，无明显空白或几何破碎。
- 手机正面视角：建筑轮廓和门厅未被草坪遮挡，但退台大多被正面立面挡住，**无法仅凭该截图判断屋顶草坪分布真实程度**。需要额外航拍视角或实际移动设备交互截图。
- 与 2017 官方文字/配图对照：**草坪式屋顶类型得到证实**，但绿化确切面积、种类、现时覆盖率、层高、排水设施和 2026 年养护状态仍无证据。本次不宣称达到照片级。

## 未完成/风险
- 多角度近距离航拍与真实测绘尺寸仍缺失，草坪覆盖形状为基于模型退台推算，不是按照片测量的轮廓。
- 圆形庭院仍是非挖方视觉示意；真实的下沉高差需要场地网格与碰撞系统联动重构。
- 当前大量其他教学楼和树木仍为程序化模型；移动端 Edge 390px 模拟并非 iPhone Safari 真机。
