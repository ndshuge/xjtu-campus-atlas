## 按影响排序

1. **性能归因与动态帧时间（P0）**：已有 Intel Edge 测试的 P95 波动大，静态 FPS 不能证明回退或改善。植被实例更新和动态阴影是待测假设；对相同场景、GPU 和画质做交替重复及单项消融，隐藏树木只用于诊断，不能作为交付优化。显存、GPU 利用率和真实功耗缺少可靠浏览器数据时标为不可用。
2. **真实移动设备稳定性（P0/P3）**：已有浏览器模拟、上下文丢失恢复代码和 R11 CDP 测试；真实 iPhone Safari 后台回收、长时发热和功耗尚无验收设备。复用测试，分别记录实际观察与模拟限制。
3. **建筑可验证真实性（P1）**：图书馆北馆四层、书库五层、南馆特定部分 49.75m 有文献；下沉庭院的位置和高差、弧形架空通道的定位均未证实。思源活动中心和西迁博物馆已有单一专属资产，不应重叠重建。先补可靠照片和无遮挡对照，不将估算称作测绘。
4. **地图与 3D 场景融合（P2）**：既有高德自定义层实测为 WebGL 1，Three.js r186 需要 WebGL 2；双 Canvas 不共享深度。隔离实验比较共享 WebGL 2 深度与双 Canvas 遮挡，使用开放校园数据及标明示意的几何，不引入商业瓦片或密钥；在完整验证前不迁移正式引擎。
5. **资源和回归控制（P2）**：目前全景 139 栋建筑、384 段道路、115 片场地、2092 株示意植被；测试渲染三角面和调用次数随机位变化，非模型独立数量。保护南门修复、搜索、圆球、移动手势及既有资产；生产构建和完整测试需在隔离树运行。
