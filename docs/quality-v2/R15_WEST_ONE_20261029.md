# 西一楼（电子与信息学部）外观重建

## 实景依据

- [Weisi Dai 的西一楼照片](https://commons.wikimedia.org/wiki/File:XJTU_West_1_Office_Building.jpg)：2013-06-03 拍摄、2013-06-05 上传，CC BY-SA 3.0。照片可见浅色瓷砖墙、较高楼体、连续窗列与分段体量；此照片仅供人工对照，没有打包为纹理。
- [校园照片资料](https://xjtu.party/photos)：对该照片说明为兴庆校区西一楼、电子与信息相关院系所在地；页面照片拍摄时间和复用授权未核实，仅作参考。
- OSM `way/263625085` 的名称为“电子与信息学部”，模型沿用其轮廓、坐标及 ID。学校校友手册亦把电子学院地址列为兴庆校区西一楼；现有 OSM 名称和拍摄点未经过实地测绘。

## 实现与不确定性

替换原先约 14 米、米黄色的通用四层体块，使用浅色外墙和多层窗列，保留 OSM 平面及交互身份。21 米及六层是依据局部照片的视觉估算，**不是测绘数据**；照片拍摄于 2013 年，整栋建筑的当前层数、屋面、分翼、入口朝向及其他立面尚未核实。当前没有复刻局部圆窗、入口及瓷砖纹理，不能声称完整还原。

原通用体块及屋顶附加方块不再绘制；独立资产沿用建筑拾取属性、相机框选高度及分类颜色接口。浏览器截图分别见 `r15-west-before/` 和 `r15-west-after/`，实际照片与画面仍有明显差距，特别是楼体分段和立面细节；手机视口仅为 Edge 模拟，不是真机 Safari。

`node scripts/verify-west-one.mjs` 检查原始数据、模型边界、有限坐标、独立归属和射线拾取；完整 `npm run verify` 与构建结果以最终运行记录为准。
