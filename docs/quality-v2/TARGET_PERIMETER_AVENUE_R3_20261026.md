## 本轮实际代码
- 新增 `src/campus-perimeter.js`：将 OSM 地理边界转成真正具有高度的墙基、立柱、两条栏杆和竖向栅条（多个 InstancedMesh）。全部建模材料、总高度约 2.3m **属于明显示意，未获现场尺寸证明**。目前映射长度约 4.4km；北门左右预留各约 43m 的清空带，其余 OSM 校门预留距离，绝不堵住主要进出口。局部门区墙体与北门现有独立模型可能有历史口径差异。
- 修改 `src/world.js`：加入围界模型；路面颜色更接近官方林荫大道参考的灰色；对 OSM 已命名林荫道的路侧树增加分叉树枝、更高的冠层及可见白色树干涂白，避免给所有道路虚构同样树种；新增 `?inspection=north-gate`、`?inspection=north-wall`、`?inspection=avenue-east` 固定镜头，用于以后与参考图逐张对照。
- 修改 `src/north-gate.js`：删除之前像随意白线的简化浮雕细节，以自然科学轨道和工程齿轮的原创几何作为**明确示意**；没有声称精确重现原作、没有使用学校版权摄影贴图。
- 新增 `scripts/verify-perimeter-avenue.mjs`；将其加入 `npm run verify`。同时让旧校门测试检查科学元素的确存在。

## 渲染与图片比对
- 桌面 1440×900：`qa-north-gate-final.png` 显示北门两侧深色板及弧门；`qa-north-wall-final.png` 显示有高度的三维围界，确认原先“只有一根边界线”的缺陷已修复。
- 桌面 1440×900：`qa-avenue-final.png` 与移动视口 390×844：`qa-avenue-mobile-final.png` 已检查，树干白色下部、较高分叉和双侧冠荫可见。摄影 QA 模式隐藏面板和标签但保留 OSM 署名，便于直观比对。对比官网照片，仍属于低多边形意象，枝形、树皮、植株间距、道路中心标线和遮荫均未精确实测。
- 北门与官方照片尚有显著差异：弧门中段及支撑尺度、浮雕构图、绿化、栏栅尺寸、室外标志和 2026 年修缮状况。2025 官方文档明确浮雕主题及尺寸，但不授权照图复刻具体造型。
- 围界全线不等于 2026 实景：除北门相邻照片外，缺少每条沿街墙段的实景/材质/高度证据。不得将本分支标为“照片级完成”。
- 软件体验：移动端此轮仅用 Edge Headless 390px 渲染审查；真机 iPhone Safari、持续 FPS 与墙体碰撞仍待验收。
