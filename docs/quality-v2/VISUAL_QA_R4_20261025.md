# 2026-10-25 · 西交兴庆校门 R4 自拍图验收

## 本轮针对用户反馈做了什么

连续比较历史照片与正在运行的 WebGL 网页实际截图，依次返工北门镜头方向、文字顺序、屋面/墙体厚度、手机裁切和纹理。

本轮第二次深化南门：老版本南门红色校名墙约宽 46.5m，只是程序字体。检查源数据时发现两枚 OSM 南门节点相距约 23m，因此重调示意校名墙宽至约 26m、增加立面高度，取消重复程序校徽和文字，将 Wikimedia Commons 历史照片 XJTU Gate.jpg (Jucember, 2011) 内的题字/校徽裁切作为材质。裁切像素位置 (192,360)-(812,453)，输出 south-gate-signage-crop.png，保留作者与 CC BY-SA 3.0 许可及派生变更说明。

## 真实浏览器截图验收

- north-final-materials-r9.png：北门校外正立面，历史字样照片纹理、白色瓷砖微纹理、弧形三维屋面可见。
- north-mobile-r8.png：390px 镜头，门檐不再因手机缩放只剩一部分；背景仍是低多边形近似，不是照片级。
- south-photo-texture-r10.png：南门从校外正面，红色牌匾与真实历史字样清晰显示，不再由生成字体模拟。
- south-photo-texture-r10-mobile.png：南门在 390x844 视口正常显示，未出现大面积网页偏移或门体完全裁断。
- 每个截图都来自正在运行的 Three.js 网页而非静态宣传合成图。静态照片**不能**证明 iPhone Safari 真机触控、GPU/跑道动态闪烁完全消失。

## 一致性与法律边界

已记录了北门原图 IronBlood (2011) 与南门原图 Jucember (2011) 的 CC BY-SA 3.0 纹理派生处理，出处 https://commons.wikimedia.org/wiki/File:XJTU_Main_Gate.JPG 和 https://commons.wikimedia.org/wiki/File:XJTU_Gate.jpg 。本项目不是根据照片生成的实测三维数据，也没有继承校方 BIM / GIS 3D 官方资产版权。

官方网络信息中心已建设历史 GIS 三维虚拟校园、全景与实景漫游：https://nic.xjtu.edu.cn/wlfw/wlfw/xnxy.htm 。由于没有获授权的原始模型和实测素材，其他四处校门和多数校园楼栋仍是 OSM 定位 + 程序化近似模型，不能声称准确复刻。

## 结论

工程层面：构建、几何回归、照片授权、移动端静态视口、GitHub Pages 在线资源可验收。

视觉层面：北门与南门比上版的形制和题字准确性有实质提升；**全校照片级真实度未达标**。部分地标仅示意，必须继续收集授权多视角实景、测量与外墙纹理后才可能达到用户期望的高质量数字孪生。
