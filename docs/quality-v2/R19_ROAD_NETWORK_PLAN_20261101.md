# R19 校园道路驾驶扩展设计与实施计划（2026-11-01）

**目标：** 在 R18 已真实上线的驾驶基础上，让车辆使用已连接的校园 OSM 内部道路网络，通过真实道路交叉口；普通校园与 R8 合成练车场保留。

**方案比较：** ① 新上完整 OSMnx、导航与地形管线：会引入冗余依赖、难以融合校内程序化平面道路；② 直接为 111 条路一次性建所有 Cannon 碰撞：简单但移动端 O(N) 静态体和射线扫描负担高；③ **选用** OSM 同点拓扑连通性与邻域碰撞流式维护，只读复用现有校园道路（经本机检查 110 条路、约 15.97km 连接）——高价值、改动少、性能可控。

**约束：** 不变造路口连接（几何交叉但 OSM 节点不同则不连）；不改 OSM；不宣称实测高程；复用 R8 Cannon RaycastVehicle、唯一渲染器和 RAF；页面启动不加载赛车；旧 R18 练车场不丢失；保留其他工作树、历史 Pages。真机 Safari 没有实机即不能标称通过。

**技术：** src/racing/road-network.js 负责道路过滤、连通分量、近邻查询；src/racing/network-physics.js 负责局部碰撞动态增删与销毁。src/racing-mode.js 仅负责切换与把当前位置给物理层。参考 OSMnx 的拓扑简化与路口处理、cannon-es RaycastVehicle / SAPBroadphase、MDN WebGL 移动端像素预算。
